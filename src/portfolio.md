      ## PENS Stack for Building Static Websites


      While WordPress is great for building dynamic websites that require a
      website database, multiple users, and custom content types (e.g. products,
      service, locations, etc.), it can be overkill for a lot of blogs or
      content-oriented websites.


      I combined the tools in the PENS tech stack for website owners who want to
      edit their own content, but who don't want a complex workflow or the site
      maintenance required with WordPress or other PHP-based content management
      systems (CMS).


      PENS uses Pages CMS for editing content, Eleventy as the SSG, Netlify for
      hosting, and Syntactically Awesome Style Sheets (SASS) as the CSS
      preprocessor.
